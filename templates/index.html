Sentinel IQ

A compact security intelligence workspace built for the TransOrg AgentIQ Datathon.

All data is synthetic. This application analyzes a fixed dataset; it does not monitor a live network. Risk scores are prioritization signals, not probabilities of compromise.

Dates are scoped relative to the latest event. Cases and notes are saved locally in this shared analyst workspace.
